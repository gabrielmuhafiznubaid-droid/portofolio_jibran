## Daftar Pertanyaan dan Jawaban
**1. Apa fungsi dari tag <header> dan <nav> pada kode di atas?**
> **Jawaban:** > - `<header>` digunakan sebagai wadah/pembungkus bagian atas website.
> - `<nav>` digunakan sebagai tempat meletakkan link navigasi utama (menu). Keduanya adal
ah tag semantic.
**2. Mengapa kita menggunakan tag <h1> dan <h2> pada bagian perkenalan?**
> **Jawaban:** > Kita menggunakannya untuk membuat judul. `<h1>` adalah judul paling utam
a (terbesar dan terpenting di mata mesin pencari), sedangkan `<h2>` adalah sub-judul pend
ukung di bawahnya.
**3. Apa kegunaan tag <a> dan apa fungsi dari atribut href?**
> **Jawaban:** > Tag `<a>` (Anchor) berfungsi membuat sebuah tautan/link. Atribut `href`
berfungsi untuk menentukan alamat tujuan ke mana link tersebut diarahkan jika diklik.
**4. Bagaimana cara memasukkan gambar ke dalam HTML dan apa fungsi atribut alt?**
> **Jawaban:** > Menggunakan tag `<img>` yang digabung dengan atribut `src`. Atribut `alt
` (Alternative Text) berfungsi memberikan teks deskripsi jika gambar gagal dimuat dan ber
guna bagi Screen Reader.
